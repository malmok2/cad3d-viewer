# CAD 3D 뷰어

논문 그림용 형상 확인 도구. 브라우저에서 STL · OBJ · PLY 를 열어 돌려 보고, 축 정면샷을 직교투영으로 찍고,
전체 치수와 단면을 걸어 PNG(3×)로 저장한다. **HTML 파일 하나로 완결** — 서버·설치·인터넷 연결이 필요 없다.

**열기:** https://malmok2.github.io/cad3d-viewer/ (GitHub Pages) 또는 `docs/index.html` 을 내려받아 더블클릭. 기본 예제로 PCHE 70° 지그재그 시험부가 들어 있다.

## 할 수 있는 것

| | |
|---|---|
| 열기 | STL(ASCII/바이너리) · OBJ(`o`/`g` 그룹은 각각 파트로) · PLY(ASCII/바이너리). 창에 끌어다 놓아도 된다 |
| 보기 | 드래그 회전 · 휠 확대 · Shift+드래그 이동. ±X ±Y ±Z 정면(직교투영) · ISO. 패널 숨기기(형상이 패널에 가릴 때) |
| 표시 | 전체 불투명도 · 전체 치수선(등각 도면식 — 아래 참고) · 격자선(와이어프레임, 사각 격자는 대각선 없이) · **윤곽선**(30° 넘게 꺾인 모서리와 열린 면의 경계만) |
| 파트 | 모두 보기 · 모두 숨기기 · 반전. 이름을 더블클릭하면 그 파트만. **파트별 불투명도**(견본을 누른 팔레트 안) — 바깥 케이싱만 투명하게, 안쪽은 불투명하게 |
| 색 | 파트마다 색을 준다. 이름 옆 견본을 누르면 팔레트가 열린다 — 정해진 9색 + 직접 고르기. 기본은 회색. **색 자동 배정** 은 켜진 파트마다 서로 다른 색을 한 번에 준다(꺼진 파트는 그대로), **색 초기화** 는 전부 회색으로 |
| 측정 | 두 점 거리와 축별 차이(Δx·Δy·Δz). 꼭짓점 가까이 누르면 꼭짓점에 붙는다. 50% 미만으로 투명한 파트는 통과해 안쪽을 잰다. 단면에 잘린 쪽은 잡지 않는다 |
| 단면 | 축 수직 / 시점 방향 / 임의 법선. 여러 개를 동시에 — 남기는 쪽의 교집합 |
| 저장 | PNG 1×–4× (배경 투명 옵션, 측정·치수 포함) · 설정이 담긴 링크 복사 (불투명도·치수·단면·색·**시점** — 같은 각도로 다시 찍을 수 있다. 형상 파일은 안 들어간다) |
| 단축키 | `1`–`6` 정면(+X +Y +Z −X −Y −Z) · `0` ISO · `P` 직교/원근 · `F` 화면 맞춤 · `D` 치수 · `W` 격자선 · `E` 윤곽선 · `T` 전체 투명 · `M` 거리 재기 · `S` PNG 저장 · `H` 패널 숨기기 · `Esc` 측정 첫 점 취소 |
| 언어 | 한국어 / English |

### 색에 대해

팔레트의 9색은 [Okabe–Ito 색맹 안전 팔레트](https://jfly.uni-koeln.de/color/)의 색상을 그대로 두고 명도만 올린 것이다.
쉐이더가 이 색에 음영(≤1)을 곱하므로, 고른 색은 **가장 밝은 지점의 색**(albedo)이 된다.
기본색은 흰색이고, 이때 렌더는 v1.0.0 과 픽셀 단위로 같다 — 색을 쓰지 않으면 예전 그림이 그대로 나온다.

자동 배정은 파트가 8개 이하면 위 팔레트에서 서로 먼 색부터 쓴다(색맹 안전). 9개 이상이면 팔레트가 모자라므로
색상환을 파트 수로 나누고 이웃한 색은 명도를 번갈아 바꾼다 — 이때부터는 색맹 안전이 보장되지 않는다.
zone 12개·20개로 시험했을 때 가장 가까운 두 색의 차이는 ΔE 15.6 · 13.7 (나란히 놓으면 뚜렷이 구분되는 수준).

### 윤곽선에 대해

두 면이 30° 보다 더 꺾인 모서리와, 면이 하나뿐인 모서리(열린 면의 테두리 — Fluent zone 경계)를 선으로 그린다.
원통을 24 등분 이상으로 나눈 면 사이(15°)는 걸리지 않는다. CAD 삼각화에 흔한 **가늘고 긴 삼각형**은 좌표 오차만으로
법선이 크게 흔들리므로(내장 형상은 int16 양자화까지 겹친다), 법선 오차를 `좌표 오차 ÷ 삼각형 높이`로 추정해
두 면의 오차 합이 9° 를 넘으면 각을 판정하지 않는다 — 평평한 면에 잡티가 찍히지 않게.
선은 면을 뒤로 미는 대신 선을 카메라 쪽으로 화면 1.5 px 당겨 그린다(가는 삼각형에서 기울기 비례 오프셋이 과장돼
가려진 선이 비치던 문제). 굵기는 화면 배율·PNG 배율과 상관없이 약 1.25 CSS px.

### 치수선에 대해

제도의 등각 치수처럼 **3D 공간에서** 그린다. 치수선은 바운딩박스 모서리를 다른 축 방향으로 띄운 선이고,
연장선·화살촉·글자가 모두 그 면 위에 놓인 채 투영된다 — 그래서 연장선이 형상의 모서리와 나란하고 글자도 그 면을 따라 기운다.
면이 37° 보다 더 옆으로 보이면 글자는 기울이지 않고 치수선을 따라 돌리기만 한다(뭉개짐 방지).

어디에 둘지는 모서리 4개 × 띄울 방향 2개 중에서 고른다. 우선순위: 글자가 화면 밖·조작 패널 밑에 가리지 않을 것 >
형상 위에 얹히지 않을 것 > 선 끝이 잘리지 않을 것 > 형상 바깥으로 멀리 · 아래쪽(가로·깊이는 바닥에) · 오른쪽.
형상이 화면을 꽉 채워 글자 둘 곳이 없으면 그 치수는 그리지 않는다. PNG 저장도 화면과 같은 자리에 그린다.

## 변환 도구 (`tools/`, 파이썬 필요)

브라우저가 직접 못 읽는 포맷은 먼저 STL/OBJ 로 바꾼다.

```bash
pip install -r requirements.txt

# STEP · IGES · BREP · SALOME HDF  →  STL   (OpenCASCADE)
python tools/cad2stl.py model.step

# Fluent .msh / .cas (gzip, 바이너리 섹션 포함)  →  OBJ (경계면 zone 별 그룹)
python tools/fluent2obj.py mesh.msh
```

- SpaceClaim: STEP 이나 STL 로 내보낸 뒤 위 절차.
- `fluent2obj.py` 는 interior 면을 뺀 경계면(inlet · outlet · wall …)만 쓴다. `--all` 이면 전부.
- `.cas.h5` / `.msh.h5`(CFF) 는 시험 파일 없이 문서대로 짠 것이라 **실행해 보지 못했다.** 구조가 다르면 파일 트리를 찍고 멈춘다 — 그 출력을 이슈로 올려 주면 맞춘다.

## 뷰어 다시 굽기

`tools/viewer_template.html` 이 소스다. `build.cmd` 를 실행하면 기본 예제(`examples/` 의 PCHE 70° 지그재그 시험부 두 형상)를
내장한 `docs/index.html` 과 홈페이지용 `docs/banner.svg` · `docs/icon.svg` 가 함께 만들어진다. 버전은 `tools/VERSION` 한 곳.

```bash
build.cmd
# 또는 직접:
python tools/build_viewer.py tools/viewer_template.html docs/index.html "이름=파일.stl" "이름2=파일2.stl"
```

STL 인자 없이 굽으면 빈 뷰어(파일 열기만)가 된다. Pretendard 글꼴(`tools/PretendardVariable.woff2`, SIL OFL)은 항상 내장된다.

## 확인한 것 / 못 한 것

- 렌더링은 화면 픽셀을 읽어 검사했다 — 테두리 0, 색상 HSV 검사, WCAG 대비(본문 17.8 · 보조 15.2 · 액센트 8.9), 스무딩 후 평면의 밝기 표준편차 0.
- v1.4.0 기능은 치수를 아는 상자 형상으로 확인했다 — +Z 정면에서 모서리 10 → 10, ISO 에서 공간 대각선 √152 → 12.3288…(꼭짓점에 붙음), 바깥 상자를 30% 로 하면 안쪽 상자 꼭짓점 (6,3,4) 을 정확히 잡는다. PCHE 플랜지 지름 84.199. 선을 켜지 않은 그림은 v1.3.0 과 픽셀 단위로 같다.
- 파트 색은 기본값(흰색)에서 v1.0.0 빌드와 같은 설정으로 찍어 비교했다 — 다른 픽셀 0. 색을 주면 형상 픽셀의 98%가 유채색이 되고, PNG 3× 내보내기에도 그대로 실린다.
- Fluent ASCII `.msh`(3D hex, zone 9개)로 변환·로드를 확인했다. 바이너리 섹션과 CFF(h5)는 시험 파일이 없어 미확인.
- 2D Fluent 메시(`(2 2)`)는 다루지 않는다.
- 앱 안 미리보기처럼 iframe 에 갇힌 창은 파일 다운로드를 막는다. 그때는 클립보드 복사나 그림 우클릭 저장을 쓴다 — 뷰어가 이 상황을 알려 준다.
